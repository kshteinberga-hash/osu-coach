# osu-coach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **This project:** the user forbids subagents, so it runs with superpowers:executing-plans, inline, with no reviewer subagent.

**Goal:** A single `osu-coach.exe` (C++, ImGui/DX11) that analyses osu! stable replays and coaches the player on timing, aim, speed and reading.

**Architecture:** There are four focused source files. `parse` reads bytes into structs, `analyze` turns a replay and a map into PlayStats, `coach` turns many PlayStats plus history into a report, and `main` holds the GUI and the `--dump` CLI. Analysis runs on a thread pool, and the GUI only reads finished results.

**Tech Stack:** C++20 on MSVC 14.44 (VS 2022 Build Tools), Dear ImGui 1.91.x (win32 + dx11 backends), LZMA SDK `LzmaDec.c`, and Python 3 for `tools/check.py` only.

**Spec:** `docs/superpowers/specs/2026-10-30-osu-coach-design.md`

## Global Constraints

- One static exe: `cl /O2 /MT /std:c++20 /EHsc`, linked with `d3d11.lib dxgi.lib d3dcompiler.lib shell32.lib ole32.lib advapi32.lib`. No other runtime dependencies.
- About 1,500 lines of our own code, not counting `third_party`. Fewer lines are better, and there is no speculative abstraction.
- Std mode only. Relax (128), Autopilot (8192) and Auto (2048) plays are skipped.
- Mod constants: EZ=2, HR=16, DT=64, HT=256, NC=512.
- Hit windows: 300 = 80−6·OD, 100 = 140−8·OD, 50 = 200−10·OD. Radius = 54.4−4.48·CS. HR: OD·1.4 and CS·1.3 (capped at 10), y → 384−y. EZ: ×0.5. DT/NC rate 1.5, HT 0.75.
- Buckets by spacing in radii: dense ≤2, stream 2–4, jump 4–7, big >7. A break is a gap over 500 ms.
- Windows: recent = the last 7 days (if there are fewer than 10 plays, the last 30 plays). Baseline = older plays plus the stored history.
- Radar = clamp(50 + 25·log2(expected/actual), 0, 100), with rates smoothed by +1 miss / +50 objects.
- Suggestion star range defaults to 3.5–4.5★.
- Paths are `std::wstring` everywhere. osu!.db strings are UTF-8 and are converted with `MultiByteToWideChar(CP_UTF8)`.
- Commit after every task, ending with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Quit or failed plays:** objects after the last replay frame + 1000 ms must not count as misses (test in Task 4).
2. **Updated maps:** if a replay's md5 isn't in osu!.db, the play counts as "map deleted" and nothing crashes (test in Task 5).
3. **Unicode song folders** (Japanese or Cyrillic): the .osu file opens through wide paths (test in Task 3).
4. **Degenerate maps:** no uninherited timing point, a single object, or spinners only must give bpm 0 and no NaN/division by zero in the stats (test in Task 2/Task 4).
5. **New player, no baseline:** the radar shows 50 with `needHistory=true`, there are no NaNs, and the verdict still renders (test in Task 6).

```cpp
struct Frame { int t; float x, y; int keys; };
struct Replay { uint8_t mode; int ver; std::string md5, player; uint16_t n300, n100, n50, geki, katu, miss;
                int score; uint16_t combo; int mods; int64_t when; std::vector<Frame> frames; };   // when = unix ms
bool readOsr(const std::wstring& path, Replay& r, bool withFrames);   // header only when !withFrames

```
- Ticks → unix ms: `(ticks - 621355968000000000) / 10000`. Frames: accumulate `w`, skip `w == -12345`, decode with `LzmaDecode` (props = the first 5 bytes, the next 8 bytes are the size, often −1, so use `LZMA_FINISH_ANY` and a growing buffer).
- osu!.db layout (version ≥ 20191106): header `int ver, int folders, bool, int64 unlock, str player, int nMaps`. Per map:
  - strings ×9 (artist, artistU, title, titleU, creator, diff, audio, md5, file)
  - `u8 status`, `u16 ×3` counts, `i64 mod`, `f32 ×4` AR CS HP OD, `f64` SV
  - 4 star lists, each `int n` + n × (`0x08 int`, `0x0C f32`); std is the first list. Versions below 20250107 use `0x0D f64` instead
  - `int drain, total, preview`, `int n` timing points × 17 bytes
  - `int bid, sid, thread`, `u8 ×4` grades, `u16 offset`, `f32 stackLeniency`, `u8 mode`, `str source, tags`, `u16 onlineOffset`, `str font`, `bool unplayed`, `i64 lastPlayed`, `bool osz2`, `str folder`, `i64 lastChecked`, `bool ×5`, `int lastModTime(unused)`, `u8 maniaScroll`
  - Skip maps whose mode is not 0.

### Task 4: Analysis engine

**Files:** Create `src/analyze.h`, `src/analyze.cpp`. Test: `tests/test.cpp`.

**Interfaces:**
- Consumes: `Replay`, `Beatmap` (Tasks 2–3).
- Produces:
```cpp
enum Cause : uint8_t { HIT, AIM, TAP, TIMING, NOPRESS };
enum Bucket : uint8_t { DENSE, STREAM, JUMP, BIG };
struct ObjRes { int t; float err, dist, spacing, gap, hold; uint8_t judge, key, cause, bucket, quad; int8_t along; bool afterBreak, inStream; };
// key 0=K1/M1 1=K2/M2; along −1 under, 0 side, +1 over (aim misses only); quad 0 TL 1 TR 2 BL 3 BR
struct StreamSeg { float bpm; int n, miss, alt, dbl; float errEarly, errLate; };
struct Acc { double n = 0, s = 0, ss = 0; void add(double v); double mean() const; double ur() const; };  // ur = 10*sd
struct PlayStats {
  std::wstring file; std::string md5, title; int bid; int64_t when; int mods; float stars, ar, od, bpm, rate;
  uint16_t g300, g100, g50, gmiss, combo; int nobj, sMiss; float acc;          // g* = game counts, sMiss = simulated
  Acc err, errKey[2], zone[4]; int within[3];                 // ±15/30/50
  int hist[100];                                              // 2 ms bins, −100..+100
  int bObj[4], bMiss[4]; double bDist[4];                     // per bucket
  int jumpHist[24]; int qObj[4], qMiss[4]; int under, over;
  int zPairs[4], zAlt[4], zOv[4], keyHits[2];
  std::vector<StreamSeg> streams; int stamNotes; float stamSec, stamNps;
  int brkObj, brkMiss, flowObj, flowMiss;
  std::vector<ObjRes> objs;                                   // kept for the miss list
};
PlayStats analyze(const Replay& r, const Beatmap& b, float stars);
```
- Zones: fast <100, switch 100–130, half 130–260, slow 260+ ms (real-time gap). Streams: ≥4 consecutive objects with spacing ≤3r and each gap within ±15% of the segment's first gap; bpm = 15000/gap. Stamina: the longest run with every gap ≤500 ms.
- The simulation follows the validated Python algorithm (the earliest unused press within the 50 window and the radius, a 400 ms look-back, presses consumed in order). Its causes: aim = a press on time but `dist > 1`; tap = a press in the window that was already used; timing = an in-radius press outside the window; nopress otherwise. Objects with `t > lastFrame.t + 1000` are dropped from every stat.

  - `test_aim_undershoot`: the 2nd press at (300−2r, 100) on time → that object has cause AIM, `along==-1`, `under==1`.
  - `test_timing`: at OD 5 the 50 window is 150 ms. A 2nd press at +150 → `judge==50`. In a separate run, a press at +160 → cause TIMING.
  - `test_tap`: one press shared between two circles 20 ms apart → the 2nd is TAP.
  - `test_hr_flip`: mods 16, presses at y' = 384−y → all hit.
  - `test_dt_rate`: mods 64, presses 15 ms late in map time → `err.mean()≈10` (real time).
  - `test_quit`: frames end at t=1200 → `nobj==1`.
  - `test_degenerate`: a one-circle map with bpm 0 → no NaN in `ur()`, `streams.empty()`.
  - `test_stream`: 6 circles 125 ms apart, 30 px apart, alternating keys → one StreamSeg with n=6, bpm=120, alt=5, and `zPairs[1]==5` (125 ms is the switch zone).

### Task 6: Coach: pp estimate, radar, weaknesses, history, verdict

**Files:** Create `src/coach.h`, `src/coach.cpp`. Test: `tests/test.cpp`.

**Interfaces:**
- Consumes: `PlayStats`, `Acc`.
- Produces:
```cpp
enum Skill { TIMING, JUMPS, BIGJUMPS, STREAMS, SPEED, READING, STAMINA, NSKILL };
struct Day { int date; int plays, objs, miss[NSKILL], obj[NSKILL]; double es, ess, en; int fcs; double accSum; };  // date = yyyymmdd
struct Weakness { Skill s; double pp; std::string metric, fix; };
struct Report { float radar[NSKILL]; bool needHistory; Weakness top[3]; int nTop; float tier; std::string verdict;
                int trend[3]; /* UR, jump, stream: +1 improving, 0 flat, −1 regressing */ std::vector<Day> days; };
double ppEstimate(float stars, float od, int nobj, float acc, int misses);
Report coach(const std::vector<PlayStats>& plays, std::vector<Day>& history, int64_t nowMs);
bool loadHistory(const std::wstring& path, std::vector<Day>& out);   // corrupt → rename to .bak, return empty
void saveHistory(const std::wstring& path, const std::vector<Day>& days);
```
- Skill → objects: TIMING = all hits (via UR), JUMPS = the jump bucket, BIGJUMPS = the big bucket, STREAMS = objects with `inStream`, SPEED = the fast+switch zones, READING = `afterBreak`, STAMINA = objects in the second half of runs ≥20 notes.
- pp, verbatim from the spec: aim = speed = (5·max(1,(SR/2)/0.0675)−4)³/1e5 · len, with len = 0.95+0.4·min(1,n/2000) and a miss penalty of 0.97^m. accTerm = 1.52163^OD·acc^24·2.83·min(1.15,(n/1000)^0.3). total = (aim^1.1+speed^1.1+accTerm^1.1)^(1/1.1)·1.14.
- Timing cost: acc recomputed as 300-share P(|e|≤w300), with e ~ N(mean, (bestWeekUR/10)²).
- Tier and verdict text verbatim: `"Ready to push to %.1f★"` / `"Still grinding %.1f★ — focus on %s"`. Trend: a change of 5% or more.
- Fix table: one `const char*` per (skill, sub-signal), with sub-signals undershoot>overshoot, overlap% >20, late-stream mean < −8 ms, and the J/K split outside 35–65%. The texts come from the spec's examples.
- history.json: `[{"d":20261030,"p":..,"o":..,"m":[..],"ob":[..],"es":..,"ess":..,"en":..,"fc":..,"as":..}, ...]`. The hand-written writer and reader handle only this shape.
